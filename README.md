# naija-shopping-festival

Konga Naija Shopping Festival 2026 landing page (starts 7 December 2026).

`index.html` is made of separate CMS blocks, one HTML document per block, each with its own copy of the shared styles:

1. Navbar, main KV, perks, Shop the Festival, Christmas Gift Finder, Flash Deals
2. HampersBundles
3. PhonesGadgets
4. Appliances
5. BrandsToGroceries (Samsung & ASUS banners, Food & Drinks)
6. Fashion
7. KidsToys
8. RemainingSection (Rate Us, SEO copy, FAQ)

Images and deal cards are placeholders. Each image placeholder shows its size and file name, with the final `<img>` tag in a comment beside it, pointing to `landingPages/2026 Marketing/NSF2026/` on Cloudinary. Links use `NSF2026*` search tags, which need to be set up on Konga search.
